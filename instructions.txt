ИНСТРУКЦИЯ ПОЛЬЗОВАТЕЛЯ

1. НАЗНАЧЕНИЕ ПРОГРАММЫ
Программа предназначена для внутренней сортировки и группировки структурированной текстовой информации об организациях методом выбора (Selection Sort).

2. ТРЕБОВАНИЯ К ВХОДНЫМ ДАННЫМ
- Формат файла: текстовый документ .txt в кодировке Windows-1251 (ANSI).
- Разделитель логических блоков: строка из 20 дефисов (--------------------).
- Синтаксис полей внутри блока:
    Название организации: <Наименование>
    Адрес: <Фактический адрес>
    Фамилия руководителя: <ФИО>
    Корреспонденция:
        - Вид: <Тип документа>, Дата: <ДД.ММ.ГГГГ>
- Особенности структуры: в рамках одной организации допускается наличие нескольких адресов, руководителей и документов корреспонденции. В случае отсутствия сведений указывается значение "нет данных".

3. ПРАВИЛА ОБРАБОТКИ И СОРТИРОВКИ
- Сортировка выполняется в оперативной памяти по одному из пяти критериев: Название, Адрес, Руководитель, Вид корреспонденции, Дата подготовки.
- Порядок упорядочения: лексикографический (по возрастанию либо по убыванию).
- При группировке по полям корреспонденции (Вид / Дата) в результирующий блок выводятся только те документы, которые соответствуют текущему значению ключа. Несоответствующие документы отсекаются.
- Записи со значением "нет данных" при любом направлении сортировки вытесняются в конец результирующего отчета.

4. СЦЕНАРИЙ РАБОТЫ С ПРОГРАММОЙ
1. Загрузка данных: выбор входного файла из списка найденных в рабочей директории либо ввод имени файла вручную.
2. Конфигурация параметров: последовательный выбор целевого поля группировки и направления сортировки.
3. Сохранение результатов: программа автоматически формирует имя выходного файла по маске:
   <ИмяИсходногоФайла>_<Поле>_<Направление>.txt
   В случае обнаружения существующего файла с таким же именем программа применяет автоинкремент индекса в скобках для исключения случайной перезаписи данных.
